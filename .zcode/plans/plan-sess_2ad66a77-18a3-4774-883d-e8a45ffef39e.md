# Customer Intelligence Manager — Build Plan

Autonomous AI employee for the Convex All Gas hackathon: listens to customer voice (web + inbox), investigates emerging issues, remembers history in Convex, reports via AgentMail. **Not a sentiment dashboard** — it answers "what changed, why it matters, what should we do."

## Stack
- **Vite + React + TS + Tailwind v4** — dashboard (no auth, single-tenant per scope control)
- **Convex** — all state, cron, actions, http routes, realtime queries
- **`@agentmail/convex` component (v0.1.0)** — inboxes, Svix-verified webhook ingest, reactive message tables, durable sending
- **OpenAI** (`openai` SDK, called from Convex actions) — structured outputs: classify signals, cluster into issues, compare history, assess impact, generate investigations/reports/chat
- **Firecrawl v2 REST** — search (investigation queries) + scrape (monitored sources, content-hash diffing)

## Layout
```
convex/

  schema.ts            — app tables
  http.ts              — /agentmail/webhook
  lib/openai.ts        — client + JSON-schema helpers

  chat.ts              — dashboard chat (reads live Convex state; can trigger investigations/sends)
  demo.ts              — scripted deterministic scenario
  cron.ts + query/mutation modules (issues, signals, activity…)
src/
  App.tsx + pages: Overview, Issues, IssueDetail, Mail, Chat, DemoPanel
  components: issue cards, trend indicators, evidence timeline, activity feed
```

## Data model (Convex tables)
`companies, sources (lastChecked/lastContentHash), watchRules, signals, issues, evidence, investigations, reports, agentTasks (live "agent working" feed), chatMessages`. Email threads/messages live in the component's tables; signals/investigations carry `emailMessageId` links.

## Agent loop
1. **Cron (every 5 min, demo-friendly)** → monitor cycle: fetch each source (HN via Algolia-through-Firecrawl, Reddit via Firecrawl search), hash-diff, only process changes
2. **Classify** new items against watch rules (LLM, structured output) → insert signals
3. **Cluster**: LLM matches each signal to existing *or historical* issues → update mentionCount, trend (7d vs prior 7d); deterministic scoring in code: frequency × growth × urgency × LLM-assessed impact/novelty × confidence
4. **Threshold crossed → investigate**: LLM generates targeted queries → Firecrawl search → scrape top hits → LLM extracts evidence w/ relevance → compare against resolved issues (persistent memory) → update issue (confidence, affectedSegment, historicalNote, recommendedAction). Every step streams to `agentTasks` → dashboard shows the agent working live
5. **Report** via AgentMail to the employee inbox

## Email (real, 3 inboxes on free tier)
`acme-intelligence@agentmail.to` (agent) · `maria@…` (employee) · `dana@…` (customer).
Webhook → classify sender: **customer** → signal + re-cluster; **employee** → interpret question → optional Firecrawl investigation → evidence-backed reply on the same thread.

## Dashboard (dark ops-console, polished)
- **Overview**: critical/emerging/stable counts, recent changes with ↑↓ multipliers, live activity feed
- **Issue detail**: summary, trend, severity, confidence, evidence links, timeline, historical context, investigation status, recommended action
- **Mail**: reactive thread viewer for the agent's inbox
- **Chat**: "What are customers complaining about this week?" → answers from live state; "investigate checkout" → triggers workflow; "email me the findings" → sends
- **Demo panel**: step-through scenario buttons + "Run investigation now"

## Demo script (deterministic, <3 min — Acme AI)
1. Seeded history: resolved issue "Checkout latency (desktop)" Aug 12–18, payment-provider timeout (persistent memory in Convex, not hardcoded)
2. Dana sends a **real email** ("checkout incredibly slow on mobile") → webhook → signal → clustering
3. Seed ramping public signals (5 last week → 23 this week)
4. "Run investigation now" → real Firecrawl corroboration, live progress
5. Issue: **Emerging — Checkout latency, ↑4.6×, 82% confidence**, "resembles Aug 12–18 incident, different segment"
6. Report email → Maria
7. Maria replies "Is this only affecting mobile users?" → agent investigates → replies with evidence
8. "Are competitors seeing the same?" → Firecrawl research → evidence-backed reply
9. Dashboard updates in realtime throughout

## Risks / notes
- Reddit blocks datacenter IPs → use Firecrawl search rather than direct reddit JSON; HN Algolia via Firecrawl verified working
- Keys untested (plan-mode restriction) — verification is build step 1, before anything else
- AgentMail free tier: exactly 3 inboxes, 100 emails/day — matches design
- Webhook registration needs the deployment URL → done right after first deploy
